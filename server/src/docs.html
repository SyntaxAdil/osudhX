OSUDHX API Reference

REST API for the OSUDHX Smart Pharmacy Management System — users, categories, products, orders, reviews, and wishlist, secured with JWT and role-based authorization.

Base URL (prod) — [Live Backend URL]
Base URL (local) — http://localhost:5000/api
Auth — JWT Bearer
Format — application/json

Conventions

All bodies are JSON. Timestamps are ISO 8601 UTC. IDs are strings. Monetary fields (price, totalAmount, priceAtPurchase) are decimals. Soft-deleted records never appear in list/detail responses.

🔒 marks endpoints requiring a JWT. A role label (e.g. Admin) marks additional role restriction.

Authentication

Stateless JWT Bearer authentication. Obtain a token from POST /api/auth/login, then send it on every protected request:

Authorization: Bearer <token>

Invalid/expired tokens → 401. Valid token, wrong role → 403.

Response Format

Success
{
  "success": true,
  "message": "Product retrieved successfully",
  "data": {}
}
Error
{
  "success": false,
  "message": "Product not found",
  "error": {}
}

Error Handling

All errors pass through a centralized Express error-handling middleware, so the shape above is consistent for validation errors, auth failures, database errors, and unhandled exceptions.

Orders

POST /api/orders 🔒 Customer

Request body
{
  "items": [
    { "productId": "prd_01h...", "quantity": 2 },
    { "productId": "prd_02h...", "quantity": 1 }
  ]
}
201 Created
{
  "success": true,
  "message": "Order created successfully",
  "data": {
    "id": "ord_01h...",
    "status": "PENDING",
    "totalAmount": 7.50,
    "items": [
      { "productId": "prd_01h...", "quantity": 2, "priceAtPurchase": 2.50 },
      { "productId": "prd_02h...", "quantity": 1, "priceAtPurchase": 2.50 }
    ]
  }
}
Stock-aware ordering: every item's stock is checked before the order is committed. Insufficient stock returns 409 Conflict. Each item's price is snapshotted into priceAtPurchase.
Order Created ↓ Check Product Stock ↓ Enough Stock? ── No ──▶ 409 Conflict │ Yes ↓ Create Order → Decrease Stock
